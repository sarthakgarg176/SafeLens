# Prompt: Multi-Modal Confidence Fusion

You are an AI Fusion Architect. Write an algorithm to fuse structural regex detections and semantic classifier topics.

## Requirements
- Parse raw regex pattern coordinates and NLP topic classifications.
- Define a weighted scoring map (e.g. if regex matches CREDIT_CARD and NLP context is Financial, boost credit card confidence).
- Handle overlapping bounding boxes by selecting the highest probability class.
- Return unified, high-confidence detections with resolved metadata.
